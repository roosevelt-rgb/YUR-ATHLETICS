The runtime source panel rechecks availability and SHA-256 for selected manifests
and contract slices. Historical counts here may drift. The source panel does not
equate a path or hash with operational health.

TERRA is a useful target for the next domain admission: assemble input contracts,
bound acquisition adapters, independent evidence datasets and domain validators
before claiming land/market diligence outcomes. The delivered factory can already
package and run text and tabular evidence analysis for such workflows, but does
not invent property data, valuation facts, or market superiority.
